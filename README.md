# Quiet Hours with Ayomide & Silvyn

A high-end, single-page interactive web experience built as a cinematic love letter.

---

## 🌟 Project Purpose
To create a deeply romantic, explicitly flirtatious, and non-linear digital space for my babe, Silvyn, emphasizing luxury, safety, and desire. The experience is designed for revisits through its dynamic "Interactive Heart" feature.

## 🛠️ Tech Stack
* **Framework:** Next.js 14+ (App Router, Client Component)
* **Styling:** Tailwind CSS (Mobile-first and fine-grained control)
* **Animation:** Framer Motion (Luxury, slow, 1.5s+ transitions)
* **Particles:** `@tsparticles/react` (Dynamic, subtle background effects)
* **Icons:** Lucide React
